# Permissões e empresas

O acesso combina Groups/Permissions (ação permitida) com `UsuarioEmpresa` (empresas permitidas). Execute `python manage.py sincronizar_perfis` para criar/sincronizar perfis padrão. A Central de Configurações permite editar grupos e vínculos. Superusuários ignoram o recorte empresarial. Usuário comum sem empresa não recebe dados operacionais.
