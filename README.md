# 🚀 VersERP

> Sistema ERP desenvolvido em Python/Django para gerenciamento
> financeiro, comercial e administrativo.

## 📖 Sobre o Projeto

O **VersERP** nasceu com o objetivo de substituir planilhas em Excel
utilizadas na empresa e evoluir para um ERP completo.

## 🎯 Objetivos

-   Eliminar controles em planilhas
-   Centralizar as informações da empresa
-   Aprender Python e Django
-   Construir um portfólio profissional

## 🛠 Tecnologias

-   Python
-   Django
-   HTML5
-   CSS3
